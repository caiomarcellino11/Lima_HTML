Principais categorias do HTML5:

Metadata Content

Flow Content

Sectioning Content

Heading Content

Phrasing Content

Embedded Content

Interactive Content

Metadata Content

<title> Informa o titulo

<meta> Definir Codificação

<link> e <style> Importar CSS

<script> Configurar o comportamento da pagina (javascript)

Flow Content

Representa a maior parte dos elementos usados no body

<div> Caixa de divisão genérica, serve para agrupar "pedaços" de código.

<p> Para colocar paragrafos na minha página.

<section> Agrupa conteúdos que partilham do mesmo assunto ou idéia.

<article> Conteúdo indpendente e completo por si só (faz sentido sozinho).

<<img> Mostra uma imagem, foto, desenho, etc. (não precisa de tag de fechamento)>

<form> Criar formulários, o usuário poderá digitar dados, enviar mensagens ou fazer login

Sectioning Content

organizar grandes áreas do documento

<section>

<article> conteúdo independene e completo por si só (faz sentido sozinho).

<aside> serve para guardar um conteúdo secundário/lateral (links relacionados, anúncios,biografia e etc).

<nav> agrupa links de navegação

Heading Content

h1, h2, h3, h4, h5, e h6 -> Para adicionar títulos e subtítulos

<hgroup> serve para agrupar elementos de título, exemplo:

Aprenda HTML

Senai Americana

Phrasing Content

Elementos que marcam textos ou partes de texto

<span> um bloco génerico, não muda nada sozinho. serve para agrupar pedaços de texto e aplicar CSS ou funções com javascript

<a> Criar um link para direcionar o usuário para outra página, utilizando o atriburo href. exemplo: clique aqui para ir ao site do bitcoin

<strong> deixar uma parte do texto em negrito

<em> deixar uma parte do texto em itálico

<mark>adciona u=um marcador em uma parte do texto Neymar

<img>Mostra uma imagem, foto, desenho. (não precisa de tag de fechamento)

embedded Content

<img> Mostra uma imagem, foto, desenho. (não precisa de tag de fechamento)

<video> Adicionar um vídeo direto no site (pode mostrar botões de play e pause)

<canvas> Criar uma tela em branco que poderá ser usado pelo javascript

<svg> Desenha gráficos baseados em vetores

<iframe> coloca outra página inteira dentro do seu website(muito usado para adicionar mapas e vídeos de outras páginas)

Interactive Content

<a> Criar um link para direcionar o usuário para outra página, utilizando o atriburo href. exemplo: clique aqui para ir ao site do bitcoin

<button>Criar um botão clicável. exemplo:

<input> Usado para receber dados. Dentro os dados aceitos estão:
type="text": campo de texto curto. type="passworld": oculta os caracteres digitados. type="email" ou type="number":valida dados especificos. type="checkbox" ou type="radio": caixas de marcação e escolha única. **** type é uma tag que não precisa de fechamento

<select>Cria uma caixa de seleção em formato de lista suspensa(dropdown)

<textarea>Cria uma "caixa" com várias linhas, serve para textos longos, comentários, mensagens

Listas em html

Lista não oerdenada(ul), exemplo:

  • item 1
  • item 2
  • item 3

Lista ordenada(ol), exemplo:

  1. item 1
  2. item 2
  3. item 3
