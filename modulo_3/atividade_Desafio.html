Atividade de Apropriação

<img> Mostra uma imagem, foto, desenho, etc. (não precisa de tag de fechamento)

<nav> agrupa links de navegação

<a> Criar um link para direcionar o usuário para outra página, utilizando o atriburo href. exemplo: clique aqui para ir ao site do bitcoin

<h2> Para adicionar títulos e subtítulos

<video> Adicionar um vídeo direto no site (pode mostrar botões de play e pause)

<input> Usado para receber dados. Dentro os dados aceitos estão:
type="text": campo de texto curto. type="passworld": oculta os caracteres digitados. type="email" ou type="number":valida dados especificos. type="checkbox" ou type="radio": caixas de marcação e escolha única. **** type é uma tag que não precisa de fechamento
